## D. LocalStorage·새로고침·오류

- [ ] `lessonconnect:bookings:v2`가 없을 때만 초기 시드를 넣는다. 사용자 삭제로 `[]`가 되면 새로고침해도 재시드하지 않는다.
- [ ] 생성·수정·취소·삭제 후 같은 origin에서 새로고침해 결과가 남는다. 다른 프로토콜/호스트/포트·브라우저 프로필·기기로 자동 공유되지 않는다.
- [ ] 유효한 v1 데이터는 v2로 마이그레이션되고 v1 원본은 보존된다. v2가 이미 유효하면 v1을 덮어쓰지 않는다.
- [ ] 손상된 JSON, 지원하지 않는 스키마 버전, 일부 필드 누락은 원본을 삭제/재시드하지 않고 읽기 오류로 안내한다. 저장 실패·QuotaExceeded는 이전 v2 전체 값을 보존한다.
- [ ] 같은 origin의 다른 탭에서 수정/삭제 후 현재 탭의 오래된 revision으로 덮어쓰지 않는다. 필요한 재조회·충돌 안내가 표시된다.
- [ ] 새로고침 후 성공 Toast가 재등장하지 않는다. 목록 조건은 URL, 스크롤 복원은 sessionStorage 범위다.
